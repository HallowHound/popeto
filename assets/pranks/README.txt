Popeto prank content

universal    used whatever the interface language is: pictures without text, sounds,
notes and speech bubbles made of symbols.
en, ru       used only when Popeto runs in that language: notes, speech bubbles and
pictures with text in that language.

Each of these folders can have:
notes.txt   one note per line (pets drag them onto the screen)
talk.txt    speech bubbles; lines under [random], [petted], [thrown], [grab], [free], [note], [window]
pictures    folder with .png pictures pets bring in
sounds      folder with .wav sounds for honking
Pets pick from universal + the current language together.
